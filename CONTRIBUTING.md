# Contributing to FutureOS

FutureOS is exploring a narrow question: can software help people preserve the quality of their reasoning before outcomes create hindsight bias? Contributions should make that question easier to test or make the product safer and clearer to use.

## Before opening a change

- Search existing issues and keep the scope small.
- For a substantial feature, open a proposal before implementing it.
- Distinguish implemented behavior from hypotheses or roadmap ideas.
- Never include real users' decision records, credentials, private analytics, or application materials.

## Local workflow

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Pull requests

A useful pull request explains the problem, the product or technical rationale, the files changed, and how the result was verified. Include before/after screenshots for visible changes. New collection of personal or behavioral data requires an explicit privacy review and corresponding documentation update.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
